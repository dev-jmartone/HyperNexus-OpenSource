ℹ️ Cómo funciona

  1. Se seleccionan los servidores a consultar.
  2. Para cada servidor HORIZON: conecta via PowerCLI, obtiene pools, VMs y sesiones.
  3. Para cada servidor VCENTER: obtiene todas las VMs con CPU, RAM y OS.
  4. Outlook/GAL clasifica usuarios por empresa y obtiene manager.
  5. Los datos se guardan en la base de datos local.
  6. Se puede generar el reporte Excel desde Reportes.
